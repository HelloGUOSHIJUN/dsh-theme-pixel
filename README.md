# dsh-theme-pixel

把 [DeepSeek Harness](https://github.com/deepseek-ai) 的 Web 界面换成**像素界面风**。

它不是把图标画成像素画，而是把整个界面按老式窗口管理器的规矩重做：**直角、硬投影、立体边框、等宽字体**。亮暗两套配色。

> **不只换色。** 这个主题会改变界面的形状语言，安装前请先读 [界面变化](#界面变化)。

## 四条规矩

整个主题只由四条规矩支撑，所有 CSS 都在执行它们：

| 规矩 | 具体做法 |
| --- | --- |
| **1 · 直角** | 所有圆角令牌归零（`xs/sm/md/lg/xl/panel` = `0px`），并对所有元素做一次全局 `border-radius: 0` 复位，原生胶囊控件也不会漏网 |
| **2 · 硬投影** | 每一级 elevation 都是**不模糊的实心偏移块**，例如 `4px 4px 0 0 #1a1a1a`，从不用高斯模糊 |
| **3 · 立体边框** | 用 2px 亮边（上/左）+ 2px 暗边（下/右）代替发丝描边；凹陷元素反过来 |
| **4 · 等宽字体** | 界面底色用等宽字体栈（SF Mono → Menlo → Consolas），代码另用一套纯等宽栈 |

## 配色

**亮色 · 纸感**

| 用途 | 值 |
| --- | --- |
| 画布 | `#e8e6df` |
| 侧栏 | `#cfccc2` |
| 卡片 | `#fdfdfb` |
| 凹陷区 | `#d8d5cb` |
| 亮边 / 暗边 | `#ffffff` / `#8a8778` |
| 主文字 | `#1a1a1a` |
| 强调蓝 | `#2b5fd9` |

**暗色 · 磷光夜**

| 用途 | 值 |
| --- | --- |
| 画布 | `#161622` |
| 侧栏 | `#0e0e18` |
| 卡片 | `#22222f` |
| 凹陷区 | `#101019` |
| 亮边 / 暗边 | `#454560` / `#05050a` |
| 主文字 | `#d8d6e8` |
| 强调蓝 | `#6fa8ff` |

强调色用的是**饱和原色**（蓝 `#2b5fd9`、绿 `#25782f`、琥珀 `#b06a00`、红 `#b3261e`、紫 `#6b3fa0`），不是柔和的品牌色——像素时代的调色板没有粉彩色。

**全部 266 个 DSH 设计令牌**在亮暗两套里都做了覆盖，包括官方 Inspect 报告的 14 个核心令牌。

## 界面变化

| 变化 | 你会看到什么 |
| --- | --- |
| **所有圆角归零** | 输入框、气泡、按钮、菜单、对话框全部变直角，胶囊控件也变方块。 |
| **等宽字体** | 正文、侧栏、菜单全部用等宽字体栈，不再是系统无衬线字体。行距相应放宽。 |
| **投影变硬块** | 卡片和浮层下面的柔和阴影变成右下方的实心方块。 |
| **菜单不再毛玻璃** | `--dsw-menu-backdrop-filter` 设为 `none`，浮层变实心——模糊会让直角边发虚。 |
| **侧栏当前行用左色条标记** | 不是整行底色，而是在左边缘加一条 3px 强调色块。 |
| **按钮按下会下沉 2px** | 按下时元素平移到自己阴影的位置，阴影消失，像真的按进桌面。 |
| **运行中的步骤闪一下** | 用终端光标的方波闪烁（`steps(1)`），这是本主题唯一允许的动画。 |

想恢复其中任何一项：在 **插件** 里停用本主题，然后刷新页面。

## 安装

```yaml
# bundle patch 插入的内容
- insert:
    - id: pixel-theme
      name: dsh-theme-pixel
```

在 **插件** 里停用即可恢复原生界面，应用其他部分不受影响。

## 兼容性

基于 DeepSeek Harness `0.2.2-rc.5` 构建。令牌层覆盖能扛住版本更新；组件层规则靠类名主干和稳定的 `data-*` 钩子匹配。

已知限制：

- **字号偏好仍然有效**：正文以 14px 为基线叠加 **设置 → 外观** 的字号设置。
- 全局 `border-radius: 0` 很激进。如果未来某个原生控件依赖圆角来表达状态（比如某些进度环），它会变成方形。
- 等宽字体的中文部分依赖系统等宽中文字体（PingFang SC / 微软雅黑），不同系统字形会略有差异。

## 自定义

所有内容都由 `scripts/build.mjs` 生成：

| 想改什么 | 改哪里 |
| --- | --- |
| 配色 | `PIXEL.light` / `PIXEL.dark` 两个对象（画布、侧栏、边、文字、强调色） |
| 圆角 | `geometry()` —— 想做成微圆角就把这几项改成 1–2px |
| 投影 | `SHADOW_LIGHT` / `SHADOW_DARK` |
| 字体 | `UI_FONT` / `CODE_FONT` |
| 边框粗细、组件形状 | 模板底部的组件规则 |

```sh
npm run build   # 重新生成 theme.css 和 client.js
npm run check   # 校验四条规矩与令牌契约
```

`npm run check` 是回归守卫，覆盖：四条规矩、266 令牌契约、字号接线、bundle 接线、locale、文档一致性、以及从 Claude 主题继承来的两类悬停回归。

## 排查

- **插件显示「异常 / 不兼容」。** bundle 声明了 `engines.dsh >=0.2.2-0`；不带 `-0` 后缀的版本范围匹配不上 `0.2.2-rc.5` 这类预发布版本。
- **装完看不到样式。** 客户端模块在页面加载时挂载，刷新一次即可。
- **和 Claude 主题同时启用会打架。** 两个主题都覆盖同一批令牌，请只开一个。
