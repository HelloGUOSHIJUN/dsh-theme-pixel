# 像素主题

把 DeepSeek Harness 的 Web 界面换成像素界面风。通过覆盖 Harness 自带的主题令牌，再加一层组件级 CSS 实现。它不改动会话、工具或快捷键的任何行为。

**它不是像素画风格，是像素界面风格**——按老式窗口管理器的规矩重做整个界面：直角、硬投影、立体边框、等宽字体。

## 四条规矩

| 规矩 | 做法 | 效果 |
| --- | --- | --- |
| **1 · 直角** | 圆角令牌全部归零，外加全局 `border-radius: 0` 复位 | 包括原生胶囊控件在内，界面上没有任何弧形 |
| **2 · 硬投影** | 每级 elevation 都是不模糊的实心偏移块 | 卡片下方是右下方的实心方块，不是雾气 |
| **3 · 立体边框** | 2px 亮边 + 2px 暗边组成凸起；凹陷元素反向 | 元素看起来像可以按下去的塑料块 |
| **4 · 等宽字体** | 界面用等宽栈，代码另用一套 | 数字对齐，中英文混排有终端感 |

## 两层的改动

**第一层：令牌（整站生效）**

| 维度 | 亮色 | 暗色 |
| --- | --- | --- |
| 画布 | `#e8e6df` | `#161622` |
| 侧栏 | `#cfccc2` | `#0e0e18` |
| 卡片 | `#fdfdfb` | `#22222f` |
| 凹陷区 | `#d8d5cb` | `#101019` |
| 亮边 / 暗边 | `#ffffff` / `#8a8778` | `#454560` / `#05050a` |
| 主文字 | `#1a1a1a` | `#d8d6e8` |
| 强调蓝 | `#2b5fd9` | `#6fa8ff` |
| 圆角 | 全部 `0px` | 全部 `0px` |
| 投影 | 实心偏移块 | 实心偏移块 |
| 菜单背景模糊 | `none` | `none` |

覆盖了全部 266 个 DSH 设计令牌，包括官方 Inspect 报告的 14 个核心令牌。

**第二层：组件形状**

- 输入卡片：凸起板块，聚焦时亮/暗边换成强调色。按下时元素平移 2px 到自己的阴影位置。
- 消息气泡：用户消息是凹陷井（inset bevel），助手消息是平纸。
- 代码块：凹陷井 + 带下边框的横幅，像终端窗口框住输出。
- 侧栏：实心色带，当前行用左边缘 3px 强调色条标记，不用整行底色。
- 菜单/对话框：凸起板块 + 硬投影，毛玻璃设为 `none`。
- 表格：2px 外框 + 隔行色带。
- 状态点变方块灯；回到底部圆钮变方形按钮。
- 聚焦环是 2px 硬描边，没有发光。

## 已知的界面变化

| 变化 | 影响 |
| --- | --- |
| **所有圆角归零** | 输入框、气泡、按钮、菜单、对话框全部变直角，胶囊控件也变方块。 |
| **等宽字体** | 正文、侧栏、菜单全部使用等宽字体栈，行距比原生略宽。 |
| **菜单不再毛玻璃** | 浮层变实心。模糊会让直角边发虚，与规矩 1 冲突。 |
| **侧栏当前行改用左色条** | 不用整行底色标记。 |
| **按钮按下下沉 2px** | 元素平移到阴影位置，阴影消失。 |
| **运行中步骤方波闪烁** | `steps(1)` 闪烁，模拟终端光标。这是主题唯一允许的动画。 |

## 使用

1. 安装后在 **插件** 中确认 `像素主题` 已启用。
2. 刷新页面（`⌘R`）。
3. 亮/暗色跟随 **设置 → 外观**；**字号设置依然生效**，叠加在 14px 基线上。
4. 想还原：停用 `像素主题` 后刷新。

## 边界

- 只改视觉，不改行为、不改快捷键。
- 全局 `border-radius: 0` 很激进：未来原生控件若依赖圆角表达状态，会变成方形。
- 中文等宽部分依赖系统字体，macOS 与 Windows 字形略有差异。
- 与 `Claude 主题` 同时启用会互相覆盖，请只开一个。
